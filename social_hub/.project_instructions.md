# Social Hub — Project Memory

## Overview
Twitter/X-style social platform built with Next.js 14 App Router, Prisma + Postgres, S3 cloud storage. Portfolio-quality demo.

## Visual Style
- **Theme**: Dark-by-default. `dark` class hardcoded on `<html>`.
- **Colors**: Midnight Blue background `#121826` (HSL 222 30% 12%), Electric Violet accent `#7F5AF0` (HSL 252 84% 65%).
- **Font**: Inter (replaces default DM Sans for this app). Loaded from `next/font/google`, mapped to `--font-sans` / `font-sans`.
- **Layout width**: max 1200px centered.
- **Animations**: Framer Motion + custom keyframes `heart-pulse`, `retweet-spin` defined in `globals.css`.

## Architecture
- **Auth**: Custom cookie-based demo session (`sh_session` cookie). NOT NextAuth. Helpers in `lib/session.ts`.
- **Demo accounts**: All users `isDemo=true` by default. Show "Demo" badge everywhere via `user.isDemo`.
- **Layout**: `components/shell/app-shell.tsx` provides sticky header + left sidebar + center main + right sidebar (Trending + Who to follow).
- **Image storage**: S3 via presigned URL flow (`/api/upload/presigned` → client PUT → `/api/upload/url` to fetch public URL). Uses `@aws-sdk/client-s3` + `@aws-sdk/s3-request-presigner`. Lib in `lib/s3.ts`, `lib/aws-config.ts`.

## Pages
- `/` Home feed (For you / Following tabs)
- `/explore` Trending hashtags + top posts
- `/notifications` Notifications list (auto-marks read on view)
- `/messages` Mock messaging UI (inbox + thread)
- `/bookmarks` Saved posts
- `/search?q=...` Search with Top/Posts/People tabs (supports `#hashtag`)
- `/[username]` Profile (banner, avatar, bio, Posts/Replies/Media tabs)
- `/post/[id]` Single post with ancestors + replies thread

## Database (Prisma)
Models: User, Post (self-relation for replies via parentId), Like, Retweet, Bookmark, Follow, Hashtag + PostHashtag, Notification (LIKE/RETWEET/REPLY/FOLLOW/MENTION), Conversation/Message.

## Seed
Idempotent: skips post-graph seeding if posts already exist. 10 dummy users with avatars from `cdn.abacus.ai`, 33 posts with varied content (text-only, images, replies, retweets), random follows, likes, retweets, sample notifications. Run via `yarn prisma db seed`.

## Important Rules
- No NextAuth. Auth = custom cookie. `getCurrentUser()` / `getSessionUserId()` from `lib/session.ts`.
- All API routes use `export const dynamic = "force-dynamic";`.
- Don't edit `next.config.js` or `package.json`.
- Tailwind: never use dynamic class names like `text-${color}` — use static palette objects (see post-actions.tsx).
- Image component: project has `images.unoptimized: true`, so `<img>` tags work fine; remote CDN URLs OK.
